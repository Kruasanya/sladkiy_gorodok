# Обучение моделей

Эта папка предназначена для разработки ML-моделей, которые помогают в операционном
и финансовом управлении бизнесом. Она использует таблицы из `Данные/Итоговые таблицы`
и справочники, собранные здесь.

## Что нужно заполнить вручную

| Файл | Кто заполняет | Статус |
|---|---|---|
| `Справочники/справочник_товаров_шаблон.csv` | владелец бизнеса | ⏳ ждёт заполнения: общее название, актуальность, срок годности, себестоимость |

## Запланированные модели

Подробное описание каждой модели (суть, данные, фичи, как обучать) — в [модели_план.md](модели_план.md).

| Модель | Готовность данных | Зависит от |
|---|---|---|
| Прогноз спроса/заказов | готова | `sales_by_counterparties` |
| Прогноз возвратов (объём) | готова | `sales_by_counterparties` (тип документа "Корректировка") |
| Рекомендация объёма производства | ждёт справочник | прогноз спроса + возвратов + срок годности + себестоимость |
| Прогноз дневного Cash Flow | готова | `bank_statement_transactions` |
| Детектор аномалий в поступлениях | готова | `bank_statement_transactions` + категоризация из `Исследование разметки транзакций/outputs` |
| Риск концентрации по контрагентам/поставщикам | готова | `sales_by_payment_counterparties` + `bank_statement_transactions` |

## Папки

- `Справочники/` — вручную заполняемые таблицы (товары, сроки годности, себестоимость).
- `Модели/01_Прогноз_спроса/` — исследование прогноза спроса и выбор рабочего бейзлайна.
- `Модели/02_Прогноз_возвратов/` — рабочая модель прогноза объёма возвратов.
- `Модели/04_Cash_Flow_и_аномалии/` — прогноз дневного cash flow, детектор аномалий и мониторинг разладки.
- `scripts/` — воспроизводимые обучающие скрипты.

## Как запустить новые модели

Из корня репозитория:

```bash
python3 "Обучение моделей/scripts/train_returns_cashflow_models.py"
```

Скрипт обучает модели возвратов, поступлений, списаний и детектор аномалий, затем пишет локальные
артефакты в `Обучение моделей/outputs/`, `Обучение моделей/figures/` и
`Обучение моделей/artifacts/`. Эти папки не коммитятся: в репозитории остаются код и markdown-выводы,
а прогнозы/графики пересобираются командой выше.
