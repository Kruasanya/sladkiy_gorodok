# Справочник товаров

Файл `справочник_товаров_шаблон.csv` нужно заполнить вручную — это связующее звено между
сырыми названиями номенклатуры в продажах (`nomenclature_raw`, 16 уникальных значений из
`Данные/Итоговые таблицы/sales_by_counterparties.csv`) и тем, что нужно моделям.

## Столбцы

| Столбец | Что писать | Зачем |
|---|---|---|
| `nomenclature_raw` | Не трогать — это исходное название из 1С. | Ключ для джойна с таблицами продаж. |
| `общее_название` | Короткое читаемое название товара без указания веса/упаковки (например: "Кокетка", "Маэстро", "Шакер-Чурек"). Если несколько `nomenclature_raw` — это один и тот же товар в разной таре, дайте им одно и то же общее название. | Таргет/ключ агрегации для прогноза спроса и возвратов — модели должны предсказывать по товару, а не по сырой строке 1С. |
| `актуальность` | `да` / `нет`. `нет` — если производство больше не выпускает этот товар. | Неактуальные товары исключаются из прогноза спроса и рекомендации объёма производства (история по ним есть, но прогнозировать дальше не нужно). |
| `срок_годности_дней` | Срок годности в днях с даты производства. | Вход для модели рекомендации объёма производства — ограничивает, насколько заранее можно производить товар про запас. |
| `себестоимость_за_единицу` | Себестоимость производства одной единицы (в тех же единицах, что и `quantity` в продажах — обычно 1 шт. упаковки указанного веса), в рублях. | Нужно для перевода прогноза в рекомендацию объёма (что производить выгодно) и для уточнения маржи в финансовом аудите. |
| `первая_продажа` | Не трогать — дата первой продажи по данным `sales_by_counterparties`. | Помогает увидеть, когда товар появился в ассортименте. |
| `последняя_продажа` | Не трогать — дата последней продажи по тем же данным. | Главный сигнал для поля "актуальность": если последняя продажа давно (например, "НЕЖЕНКА" — 2025-12-30, "Сладкоежка"/"Шакер-Чурек" — май-июнь 2025), товар, вероятно, уже не производится — проверьте и поставьте `актуальность = нет`. |
| `комментарий` | Свободное поле — любые пояснения (сезонность, замена рецепта и т.п.). | Контекст для дальнейшего анализа, не используется моделью напрямую. |

## Как заполнять

- Один товар = одна строка, даже если у него несколько весовых/упаковочных вариантов в 1С (просто опишите это в комментарии и используйте отдельные строки на каждый `nomenclature_raw`, но с одинаковым `общее_название`).
- Не меняйте и не удаляйте строки `nomenclature_raw` — список сверен с данными продаж. Если появится новый товар в будущих выгрузках, добавьте новую строку.
- Если для товара несколько разных себестоимостей за период (менялась рецептура/цены сырья) — занесите актуальную на сегодня; динамику себестоимости по времени добавим отдельной таблицей, если понадобится.
